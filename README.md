# gateway 网关

> 网关为什么用spring-cloud-gateway而不是zuul，
> gateway支持响应式编程，适用一些高流量的场景
> 提供了丰富的过滤器机制。
> zuul不支持响应式编程，2.0版本后闭源，不适用高并发场景。
